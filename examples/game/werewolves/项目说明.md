## 🚀 快速开始

### 1. 环境准备

**前置要求：**
- Python 3.8+
- DashScope API Key（通义千问API）

**安装步骤：**

**步骤1：安装 AgentScope 框架**（必须先做！）
```bash
# 进入 agentscope 根目录
cd yours\agentscope

# 以开发模式安装 AgentScope
pip install -e .
```

**步骤2：安装狼人杀项目依赖**
```bash
# 进入狼人杀项目目录
cd examples\game\werewolves

# 安装额外依赖
pip install -r requirements.txt
```

> **为什么需要 `pip install -e .`？**
> - `-e` 表示以**可编辑模式**安装，修改源码后无需重新安装
> - 狼人杀项目依赖 `agentscope` 包中的核心模块（Agent, Model, Formatter等）
> - 如果不安装 agentscope，会报错 `ModuleNotFoundError: No module named 'agentscope'`

### 2. 配置 API Key

**Windows (PowerShell):**
```powershell
$env:DASHSCOPE_API_KEY="your-api-key-here"
```

**Linux/Mac:**
```bash
export DASHSCOPE_API_KEY="your-api-key-here"
```

运行测试
```bash
python simple_test.py
```

### 3. 运行游戏

**使用官方Agent（测试用）：**
```bash
python main.py
```

**使用自定义Agent（你的实现）：**
编辑 `main.py` 第94行：
```python
# 将这一行：
#players = [get_official_agents(f"Player{_ + 1}") for _ in range(9)]

# 改成：
players = [PlayerAgent(f"Player{_ + 1}") for _ in range(9)]
```

然后运行：
```bash
python main.py
```

### 4. 启用可视化（可选）

**步骤1：安装Studio**
```bash
pip install agentscope[studio]
```

**步骤2：启动Studio服务器**（新终端窗口）
```bash
agentscope-studio
```

**步骤3：取消注释 main.py 中的Studio配置**
```python
# 在 main.py 第86-90行取消注释：
import agentscope
agentscope.init(
    studio_url="http://localhost:3000",
    project="werewolf_game",
)
```

**步骤4：打开浏览器查看**
访问 `http://localhost:3000` 实时查看游戏进程

## 🤖 Agent.py 详解

`agent.py` 是整个项目的核心，实现了一个智能狼人杀玩家。

### 整体架构

```
agent.py
├── DecisionMaker (决策制定模块)
│   ├── 夜间决策（狼人杀人、预言家查验、女巫用药、猎人开枪）
│   └── 白天决策（发言、投票）
│
├── RiskAssessment (风险评估模块)
│   ├── 评估行动风险
│   ├── 计算生存概率
│   └── 评估胜利概率
│
├── TeamCoordination (团队协作模块)
│   ├── 识别队友（狼人）
│   ├── 协调策略
│   └── 管理临时联盟
│
├── PlayerMemory (玩家记忆系统)
│   ├── 当前游戏状态
│   ├── 跨局学习数据
│   └── 玩家行为模式
│
└── PlayerAgent (主Agent类)
    ├── 动态Prompt生成
    ├── 消息观察与处理
    └── 状态保存与加载
```

### 核心类说明

#### 1. **DecisionMaker - 决策制定模块**

负责在不同阶段做出决策：

```python
class DecisionMaker:
    def night_phase_decision(self, role, game_state):
        """夜间阶段决策"""
        # 根据角色返回不同的决策
        
    def day_phase_decision(self, game_state):
        """白天阶段决策（发言+投票）"""
        
    def werewolf_kill_decision(self, game_state):
        """狼人杀人决策：优先目标排序"""
        
    def seer_check_decision(self, game_state):
        """预言家查验决策：选择可疑玩家"""
        
    def witch_potion_decision(self, game_state):
        """女巫用药决策：何时救人/毒人"""
```

**关键方法：**
- `night_phase_decision()`: 夜晚行动选择
- `day_phase_decision()`: 白天发言和投票
- `generate_speech()`: 生成发言建议
- `make_vote_decision()`: 投票决策

#### 2. **RiskAssessment - 风险评估模块**

评估各种行动的风险和收益：

```python
class RiskAssessment:
    def evaluate_action_risk(self, action, game_state):
        """评估行动风险 (0-1)"""
        # 'reveal_identity': 暴露身份风险
        # 'aggressive_vote': 激进投票风险
        # 'use_ability': 使用技能风险
        
    def assess_win_probability(self, current_state):
        """评估当前胜利概率"""
        
    def calculate_survival_probability(self, targets, game_state):
        """计算目标生存概率"""
```

**风险类型：**
- 身份暴露风险
- 激进行动风险
- 技能使用风险
- 生存概率计算

#### 3. **TeamCoordination - 团队协作模块**

管理队友关系和协作策略：

```python
class TeamCoordination:
    def identify_teammates(self, observations):
        """识别队友（主要用于狼人）"""
        
    def coordinate_with_team(self, teammates, strategy, game_state):
        """与队友协调策略"""
        
    def update_trust_score(self, player, action, outcome):
        """更新对玩家的信任度"""
```

**主要功能：**
- 狼人队友识别
- 击杀目标协调
- 投票策略同步
- 信任度管理

#### 4. **PlayerMemory - 记忆系统**

跨局学习的核心：

```python
class PlayerMemory:
    # 当前游戏状态
    current_game = {
        'role': None,
        'alive_players': [],
        'dead_players': [],
        'night_results': [],
        'speeches': [],
        'votes': []
    }
    
    # 跨局统计
    total_games: int
    wins: int
    role_stats: dict  # 各角色胜率
    
    def update_from_msg(self, msg):
        """从游戏消息中提取信息"""
        
    def record_game_result(self, won):
        """记录游戏结果，更新统计"""
        
    def get_insights_for_prompt(self):
        """生成经验总结，用于Prompt"""
```

**记忆内容：**
- 当前局游戏状态
- 历史战绩统计
- 各角色表现
- 玩家行为模式

#### 5. **PlayerAgent - 主Agent类**

继承自 `ReActAgent`，整合所有模块：

```python
class PlayerAgent(ReActAgent):
    def __init__(self, name):
        """初始化Agent和策略模块"""
        self.player_memory = PlayerMemory()
        self.decision_maker = DecisionMaker(name)
        self.risk_assessment = RiskAssessment()
        self.team_coordination = TeamCoordination(name)
    
    @property
    def sys_prompt(self):
        """动态生成Prompt（核心！）"""
        # 基础规则 + 角色策略 + 记忆经验 + 策略建议
        
    async def observe(self, msg):
        """观察游戏消息，更新状态"""
        # 识别角色、更新记忆、判断游戏结束
        
    def state_dict(self):
        """保存状态（用于检查点）"""
        
    def load_state_dict(self, state):
        """加载状态（恢复检查点）"""
```

**关键特性：**
- **动态Prompt**：根据角色、记忆、局势动态生成提示词
- **消息观察**：自动识别角色分配、游戏结束等关键信息
- **状态持久化**：支持保存/加载，实现跨局学习

### Agent的工作流程

```
游戏开始
    ↓
接收角色分配消息 → observe() 识别角色 → 更新 current_role
    ↓
生成动态Prompt → sys_prompt 属性
    ↓
    ├─ 基础游戏规则
    ├─ 角色专属策略（狼人/预言家/女巫/猎人/村民）
    ├─ 记忆经验总结（胜率、角色表现）
    └─ 实时策略建议（风险评估、决策建议）
    ↓
接收游戏消息 → observe() 更新记忆
    ↓
LLM基于Prompt生成回复 → 发言/投票/行动
    ↓
循环直到游戏结束 → record_game_result() 更新统计
    ↓
保存状态 → state_dict() 序列化
```

## 🛠️ 如何自定义Agent

### 方式1：优化现有策略模块（推荐）

修改 `agent.py` 中的四个策略类：

**示例：改进狼人击杀决策**
```python
def werewolf_kill_decision(self, game_state: dict) -> dict:
    """狼人杀人决策"""
    alive_players = game_state.get('alive_players', [])
    speeches = game_state.get('speeches', [])
    
    # 你的改进逻辑：
    # 1. 分析发言，识别预言家特征
    suspected_seer = self._advanced_seer_detection(speeches)
    
    # 2. 识别女巫（第一晚救人的可能性）
    suspected_witch = self._identify_witch(game_state)
    
    # 3. 优先级排序
    priority_targets = []
    if suspected_seer:
        priority_targets.append(suspected_seer)
    if suspected_witch:
        priority_targets.append(suspected_witch)
    
    return {
        'suggested_targets': priority_targets,
        'reasoning': f'优先消灭预言家 {suspected_seer}'
    }
```

### 方式2：增强Prompt（高性价比）

80%的智能来自Prompt！修改 `_get_role_specific_prompt()`:

```python
def _get_role_specific_prompt(self):
    """添加更详细的策略指导"""
    if self.current_role == 'werewolf':
        return """
# 狼人高级策略
1. 识别预言家技巧：
   - 留意谁在第二天发言时提供详细的验人信息
   - 注意谁在投票时显得很有自信
   
2. 伪装技巧：
   - 第一天可以伪装成村民，发言要中立
   - 如果要跳预言家，必须提前规划好验人结果的逻辑
   
3. 团队配合：
   - 避免狼人集体投同一人（太明显）
   - 至少要有一个狼人伪装成好人带节奏
"""
```

### 方式3：完全自定义Agent

创建新的Agent类：

```python
class MyCustomAgent(ReActAgent):
    def __init__(self, name):
        # 你的自定义初始化
        super().__init__(
            name=name,
            sys_prompt=self._build_my_prompt(),
            model=DashScopeChatModel(...),
        )
    
    async def observe(self, msg):
        # 你的观察逻辑
        return await super().observe(msg)
```

## ❓ 常见问题

### Q1: 游戏运行很慢？
**A:** 这是正常的，因为：
- 每个玩家都是独立的AI Agent
- 需要调用通义千问API（有网络延迟）
- 9个玩家 × 多轮对话 = 大量API调用

**优化建议：**
- 使用更快的模型（如 `qwen-turbo`）
- 减少讨论轮数（修改 `utils.py` 中的 `MAX_DISCUSSION_ROUND`）

### Q2: API调用超时或报错？
**A:** 检查：
1. API Key是否正确设置
2. 网络连接是否正常
3. DashScope账号是否有足够余额

### Q3: 如何调试Agent的决策？
**A:** 在 `agent.py` 中添加日志：
```python
def werewolf_kill_decision(self, game_state):
    decision = self._make_decision(game_state)
    print(f"[DEBUG] {self.name} 狼人决策: {decision}")
    return decision
```

### Q4: 游戏中途崩溃了怎么办？
**A:** 游戏支持断点续玩：
- 检查点保存在 `checkpoints/` 目录
- `main.py` 会自动加载上次的检查点
- 如果要重新开始，删除 `checkpoints/players_checkpoint.json`

### Q5: 如何测试单个Agent？
**A:** 创建测试文件 `test_my_agent.py`:
```python
import asyncio
from agent import PlayerAgent
from agentscope.message import Msg

async def test():
    agent = PlayerAgent("TestPlayer")
    
    # 模拟角色分配
    role_msg = Msg(
        name="Moderator",
        content="[TestPlayer ONLY] your role is werewolf",
        role="system"
    )
    await agent.observe(role_msg)
    
    print(f"角色: {agent.current_role}")
    print(f"Prompt预览: {agent.sys_prompt[:500]}...")

asyncio.run(test())
```

### Q6: 如何查看Agent的内部状态？
**A:** 使用断点或打印：
```python
# 在 PlayerAgent 的 observe() 方法中添加
print(f"[{self.name}] 当前角色: {self.current_role}")
print(f"[{self.name}] 存活玩家: {self.player_memory.current_game['alive_players']}")
print(f"[{self.name}] 历史战绩: {self.player_memory.wins}/{self.player_memory.total_games}")
```

## 📊 性能优化建议

### 1. Prompt优化
- ✅ 简洁明确（避免超长Prompt导致token浪费）
- ✅ 关键信息放在最前面
- ✅ 使用结构化的格式（列表、标题）

### 2. 决策优化
- ✅ 简单规则优先（不需要AI处理的用规则）
- ✅ 缓存常用决策
- ✅ 避免重复计算

### 3. API优化
- ✅ 使用更快的模型
- ✅ 减少不必要的API调用
- ✅ 批量处理（如果可能）
